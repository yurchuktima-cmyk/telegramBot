Телеграм-бот для зручного збереження фільмів. Великий функціонал бота має такі команди як:
/start
/films
/delete_movie
/filter_movie
/search_movie
/edit_movie
/create_film
/search_by_actor
У боті була використана бібліотека Aiogram та бот, що допоміг отримати токен — @BotFather.


Зараз я хочу розповісти про те, за що відповідають файли проєкту:

Bot.py — основа бота з багатьма обробниками команд, імпортами тощо.

Commands.py — відповідає за реєстрацію команд у боті та зручне користування ними.

Data.py — файл для збереження функцій, щоб працювати з даними.

Data.json — тут зберігаються наші фільми.

External.py — використовується як декоратор для логування дій у боті.

Functions.py — збереження зображення за посиланням.

Models.py — описує модель даних.


Бот може бути корисним для створення власної бібліотеки фільмів та фільтрації їх.


Бот — це фінальний проєкт учня академії GoITeens Тимофія. Від себе хочу подякувати своєму викладачу Evtefeev Nikita за допомогу при виникненні помилок.
